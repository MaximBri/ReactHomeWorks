## Задание 6

Написан хук `useToggle`. Основной задачей хука является **переключение между значениями массива** (или между `true` и `false` в случае, если массив не был передан)

Возвращает массив из двух элементов:

- Первый указывает на текущее значение (элемент списка)
- Второй - фукция, которая меняет значение на следующее по списку. Может принимать 1 параметр, который будет добавлен следующим элементом в общий список.
