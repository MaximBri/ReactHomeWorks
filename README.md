## Задание 5

Написан хук `useWindowScroll`. Основной задачей хука является получение **текущего положения скролла**

Возвращает массив из двух элементов:

- Первый указывает на координаты скролла
- Второй - фукция, которая скроллит пользователя наверх

При скролле значения позиции скролла меняются
