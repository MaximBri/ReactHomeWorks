## Задание 2

Написан хук `useLocalStorage`. На вход принимает **1 параметр** - ключ, по которому будет устанавливаться значение в `LocalStorage`.

Возвращает массив из двух элементов: **первый** - само значение, **второй** - объект со свойствами:

- `setItem`: устанавливает новое значение. Принимает 1 параметр - строку, которая будет установлена.
- `removeItem`: чистит значение как в `useState`, так и в `LocalStorage`
