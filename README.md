# О приложении:

## Страницы:

1. Главная. Находится навигация на страницы авторизации и регистрации
2. Регистрация. Находится форма с регистрацией
3. Авторизация. Находится форма с авторизацией

## О авторизации:

Вверху находится навигация на главную страницу и страницу регистрации.
Содержит 2 поля: логин и пароль, кнопку отправки.

Если одно из полей не заполнено на момент отправки, то пользователь увидит ошибку в соответствующем поле

## О регистрации:

Вверху находится навигация на главную страницу и страницу авторизации.
Содержит в себе 6 полей: имя, никнейм, почта, пол, пароль, повторный пароль.
Если какое-то поле пусто на момент отправки, то пользователь увидит ошибку в соответствующем поле. Дополнительно проверятеся на валидность почта.
