# README

## Задание 1:

Написан кастомный хук `useFetch()`, который принимает 1 параметр - ссылку, по которой будет идти `get` запрос.

Внутри себя хук содержит 3 состояния: данные (data), процесс загрузки (isLoading), ошибку (error).

Есть метод `refetch`, который может принимать объект с параметрами (необязательный).

**Хук возвращает объект с полями:**

- `data` - непосредственно данные, полученые по запросу
- `isLoading` - индикатор загрузки: запрос заверишлся или ещё нет
- `error` - текстовое поле ошибки (по умолчанию равен пустой строке)
- `refetch` - метод, который принимает пропсы, передаёт их в функцию, отвечающую за сам запрос.
