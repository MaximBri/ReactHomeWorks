## Задание 4

Написан хук `useViewportSize`. Основной задачей хука является получение **текущих размеров экрана**

Возвращает объект с параметрами:

- `width`: ширина экрана
- `height`: высота экрана

При увеличении/уменьшении масштаба (или экрана через `DevTools`) хук реагирует и подставляет в компонент `<Demo />` актуальные значения.
